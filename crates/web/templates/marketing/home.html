Quickstart

One binary. A config file. You're tracking.

Embedded mode needs no database to set up. Drop the tracker snippet into your site, point Sentinel at your LLM gateway, and the dashboard lights up.

Sign in View on GitHub
# 1. Build & run $ cargo run --release --bin stomatopod # 2. Track a pageview from your site <script src="https://your-host/tracker.js" data-site="<public-key>"></script> # 3. (Optional) Wire Sentinel for agents $ sentinel \ --upstream https://api.anthropic.com \ --stomatopod-url https://your-host \ --token "<sentinel-token>"
