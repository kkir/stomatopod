Sentinel · AI Firewall

Catch runaway agents before they catch your CFO's eye.

Sentinel is a sidecar proxy and policy engine that sits between your agent and its LLM. It ingests every span, totals up tokens and dollars, watches for tool loops, and pulls the plug when an agent crosses a line.

What Sentinel watches

Observability that doubles as a kill switch.

Span ingest

Every LLM call, tool call, and reasoning step lands as a structured span. Bearer-token auth; per-site routing.

Token & cost accounting

Per-agent, per-session, per-model. Dollars are computed in the backend so you can change provider pricing in one place.

Repetition detection

Flags loops where an agent calls the same tool with the same arguments. The classic "stuck-in-a-while-loop" failure mode — caught in real time.

Token velocity caps

Limit tokens consumed per minute or per session. Sentinel sees the runaway before the OpenAI bill does.

Cost thresholds

Hard ceilings in dollars. When an agent crosses one, Sentinel opens an incident and signals the sidecar to stop.

SSE control stream

Sidecars subscribe to a server-sent-events stream. Kill commands arrive in milliseconds. Slow consumers lag rather than block the publisher.

Architecture

A sidecar in front of the model. A backend behind the dashboard.

No SDK rewrite. Sentinel intercepts at the HTTP layer, emits spans, and listens for kill commands. Your agent code doesn't change.

Policies

Declare a budget. Sentinel enforces it.

Policies are evaluated as spans land. The first threshold a span trips opens an incident and broadcasts a stop signal to that agent's sidecar.

  • Cost cap — hard dollar ceiling per agent or session.
  • Token velocity — max tokens per minute.
  • Tool repetition — same tool + args N times in a row.
  • Property redaction — configurable keys stripped before storage.
# stomatopod.toml — Sentinel section [sentinel] redact_keys = ["api_key", "password"] [sentinel.policies.cost] max_usd_per_session = 5.00 [sentinel.policies.velocity] max_tokens_per_minute = 60000 [sentinel.policies.repetition] max_identical_tool_calls = 5
