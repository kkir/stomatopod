Foundations

What you can put in a security review.

Stomatopod is a foundation for compliant deployments, not a compliance claim. The features below are the pieces a real review will care about.

Data residency

Embedded storage writes Parquet files to a directory you control. Want it in eu-west? Run it in eu-west.

No third-party trackers

The tracker calls your host. Nothing else. No CDN script tags, no analytics pixels, no cross-site requests.

IP anonymization

The last octet of IPv4 is zeroed before anything reaches storage. Geo lookup runs against the anonymized address.

Cookieless sessions

No cookies dropped on visitors. No persistent fingerprint stored.

PII redaction for spans

Sentinel strips configured property keys (API keys, passwords, PHI fields) before storing tool-call data.

AGPL-3.0 source

Read every line. Audit the data path end to end. Fork it if you need to.
