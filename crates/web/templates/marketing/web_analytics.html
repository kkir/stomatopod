What it does

Everything you actually look at in GA. None of the bloat.

Cookieless sessions

Sessions derive from a hash of IP + user-agent. No cookies set, no fingerprinting beyond what the browser already sends.

IP anonymization

The last octet of IPv4 is zeroed before anything reaches storage. Geo lookup runs against the anonymized address.

Custom events & properties

Send arbitrary named events from the tracker. Each event carries a JSON property bag you query in the dashboard.

Funnels

Define multi-step conversion funnels. Drop-off, conversion rate, and per-step counts — on real session timelines.

Referrers, UTM, devices

Top pages, top referrers, browsers, devices, countries — the columns you scan first, laid out where you expect them.

Real-time ingest

Events land in an in-memory channel, batch-flush to Parquet on a configurable interval. Sub-second dashboards on modest hardware.

vs. Google Analytics

A different deal.

GA gives you a free dashboard in exchange for shipping every visitor's behavior to Google. Stomatopod gives you the dashboard in exchange for running a small Rust process.

Your data stays on your servers. No third-party requests in the tracker.

Install

One script tag. That's the integration.

Drop a tracker snippet into your <head> with your site's public key. No SDK to install, no bundle to ship.

  • 1.4 KB minified, no dependencies
  • Captures pageviews automatically
  • stomatopod('event', name, props) for custom events
  • Long-cache headers; visitors pay for it once per year
<!-- Drop into <head> --> <script src="https://your-host/tracker.js" data-site="<your-public-key>" defer> </script> // Custom event from anywhere stomatopod('event', 'signup', { plan: 'pro', source: 'launch_page', });
