# stomatopod

Use [`mise` tasks](https://mise.jdx.dev/tasks/) for local development.

## Prerequisites

1. Install `mise` (see <https://mise.jdx.dev/getting-started.html>).
2. Install toolchain versions declared in `mise.toml`:

```bash
mise install
```

## First-time setup

```bash
mise run config:init
```

Then set `auth.secret_key` in `stomatopod.toml`, or export:

```bash
export STOMATOPOD_AUTH__SECRET_KEY="replace-with-a-long-random-secret"
```

## Daily commands

```bash
mise run dev          # run the API/ingest server (serves the SPA + JSON at /app, /api/v1)
mise run check        # fmt + clippy + tests
mise run test         # Rust tests only
mise run e2e          # Playwright end-to-end tests
```

## Dashboard UI (Dioxus SPA)

The dashboard is a Dioxus 0.7 client-side WASM app in [`crates/ui`](./crates/ui),
styled with Tailwind CSS v4. The server (`crates/web`) embeds the built bundle
(via `rust-embed` from `crates/web/ui-dist/`) and serves it at `/app`, alongside
the JSON API at `/api/v1`. `/login` stays server-rendered.

```bash
# Live-reloading UI dev loop: run the API server and the dx dev server together.
mise run dev          # terminal 1: API on :8080 (dx proxies /api, /login, /logout to it)
mise run ui:dev       # terminal 2: dx serve with hot reload

# Production/CI: build the bundle so the release binary can embed it.
mise run ui:bundle    # dx bundle --release → crates/web/ui-dist/
```

`crates/web/ui-dist/` is gitignored (built artifact) and regenerated by
`mise run ui:bundle` locally and by the Docker build. A release binary built
without a bundle serves a 503 that says to run `mise run ui:bundle`.

## Deployment

See [`DEPLOY.md`](./DEPLOY.md) for running Stomatopod in production, including the
**data persistence** requirement (mount a volume at `/app/data`) and ready-to-use
[`docker-compose.yml`](./docker-compose.yml). The [`Dockerfile`](./Dockerfile)
installs `dx`, builds the SPA bundle, and embeds it into the release binary, so
`docker build` needs no separate UI step.

## Notes

- `mise run dev` fails fast when auth config is missing.
- The `dx` CLI (`cargo:dioxus-cli`) and the `wasm32-unknown-unknown` target are
  required for the UI; `mise install` provisions `dx`, and `dx` installs the
  wasm target on first run.
